Checksum Calculator

A checksum is a small value calculated from the data and sent along with it. The receiver recalculates it. If the values do not match, the data was corrupted and the packet is dropped.

How it works

    

      

        
Internet checksum

        
    
          
  • Split the data into 16-bit words.
    • 
          
  • Add them all; any carry beyond 16 bits is added back in (one's complement addition).
    • 
          
  • Invert all bits. The result is the checksum.
    • 
          
  • Receiver adds data + checksum. If the result is 0xFFFF, the data is valid.
    • 
        

      

      

        
Simple sum checksum

        
    
          
  • Add the value of every byte.
    • 
          
  • Keep only the remainder after dividing by 256.
    • 
          
  • Receiver repeats the sum and compares it with the received checksum.
    • 
        

      

      

        
Try this

        
    
          
  • Calculate, then press Corrupt 1 character and Verify.
    • 
          
  • Switch to Simple sum and press Swap first 2 characters: the error is not detected.
    • 
          
  • Do the same with Internet checksum: it is detected.
    • 
        

      

    


    

      Note: real Ethernet frames use a stronger check called CRC-32 (the FCS field),
      while IP, TCP and UDP headers use the Internet checksum.
