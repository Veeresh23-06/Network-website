Wireless Connections

Wireless networks use radio waves, microwaves or light instead of cables. Here are the main types and how a Wi-Fi link is made.

How a Wi-Fi connection is made

1. Discover

The access point broadcasts beacon frames with its network name (SSID). The laptop scans and finds it.

2. Authenticate

The laptop proves it is allowed to join, using the Wi-Fi password (WPA2 or WPA3).

3. Associate

The laptop joins the access point and agrees on speed and settings.

4. Get an IP address

DHCP gives the laptop an IP address, gateway and DNS server.

5. Send data

Traffic goes laptop → access point → switch/router → internet.
